# 输出目录与绝对单图规则

## 目的

自动规划必须先确定输出角色、落库位置和单元类型，再确定目录和独立图文件。后续源码和运行只能按规划表执行，不能自行改变输出身份、路径或把多个图合并进一个文件。

## 路径列

规划表中的具体路径拆分为：

`输入根目录 | 输入子目录或文件 | 输出根目录 | 输出子目录或文件`

根目录列固定写 `$ResearchProjectsRoot` 之后、以项目名开头的项目相对路径；子目录或文件列写根下相对路径或具体文件名。不得保存盘符、用户名、电脑同步根或项目根之前的部分。

新任务输出根固定对应：

`<项目名>/03_数据与分析/skill化工作记录/YYYYMMDD/结果/单元库`

每日 `test/单元库` 只由固定 `run_pipeline.ps1 -TestMode` 在复现时派生，不进入规划表，也不改变正式输出路径和文件名。用户提供的主单元库和主解释目录只作为已有输入与解释体系来源，不作为本次新输出根。

历史微调必须继续使用原日期目录、原 `结果/单元库` 根和原正式输出身份，不创建新时间戳或版本副本。

## 落库规则

先按内容判断输出角色，再确定落库位置：

- 基础数据 → `信息单元库`
- 分析结果 → `图文单元库/文`
- 图形结果 → `图文单元库/图`

正式保留的专用绘图输入统一进入本次 `结果/单元库/图文单元库/文`，不得放入信息单元库，也不得只留在工作记录目录作为未解释临时文件。既有库中即使已有可直接绘图的数据，也只能作为 Python 前置步骤的输入，不能成为 R 的直接输入。

不得因为文件扩展名是 `.tsv`、`.csv` 或 `.xlsx` 就自动放入信息单元库。结构类型只说明文件怎样解释，内容角色决定落库位置。

## 输出子目录

`输出子目录或文件` 必须包含能表达分析主题、科研问题或结果层级的语义子目录。禁止把所有图、表或文本堆在库根目录或一个无语义目录中。

除非用户明确要求根级索引文件，并且规划表写清理由，新输出不得直接落到 `信息单元库`、`图文单元库/图` 或 `图文单元库/文` 根目录。

## 图形文件对

每个独立图固定输出：

- 一个 PDF 主文件。
- 一个同名 TIF 备用文件，300 dpi。

两者必须位于同一科研主题子目录，表达完全相同的单图。默认不输出 PNG。

需要 N 个图时，必须规划 N 个独立 PDF/TIF 文件对。一个 R 脚本可以循环生成多对文件，但每次必须为一个单图单独打开、写出并关闭输出，不得把多个图写进同一个 PDF 或 TIF。

## 绝对单图硬规则

每个图形文件必须满足：

`一个 PDF = 一页 = 一个主要数据面板 = 一个独立科研图形`

对应 TIF 必须只包含同一个独立单图。

这不是默认偏好，而是 03 数据分析不可解禁的产物约束。即使用户要求组合，也必须拆成多个独立图文件；物理拼版不在本流程中完成。

禁止：

- A/B/C/D 多面板、上下组合、左右组合或任意拼接。
- `facet_wrap()`、`facet_grid()` 或其它分面。
- 主图加 inset 小图、边际分布图或第二个数据坐标区。
- 热图旁拼接另一个独立数据图或独立科研面板。
- `patchwork`、`cowplot::plot_grid()`、`gridExtra::grid.arrange()`、`ggpubr::ggarrange()`。
- `par(mfrow=...)`、`par(mfcol=...)`、`layout()`、`split.screen()`。
- 在同一个图形设备中连续打印多个图。
- 通过 grob、viewport、手工布局或未列出的组合方式把多个数据图放进同一画布。
- 多页 PDF、多帧 TIF，以及一个文件内的任何第二个独立数据面板。

一个 R 对象即使技术上只有一个返回值，只要视觉结果含两个或更多独立数据面板，同样违规。

允许保留标题、副标题、坐标轴、图例、色标、文字标签、显著性标记、参考线、回归线、置信区间和同一坐标系中的多个数据层。这些元素不得建立第二个独立科研问题或数据坐标面板。

## 规划检查

每个图输出必须在规划表中分别写清：

- 独立科研问题。
- 单一主要数据面板。
- 专用绘图输入。
- 唯一 PDF 名。
- 同名 TIF 名和 300 dpi。
- 图类型、横纵轴、视觉编码、图例和注释。
- `loose_visual` 复现策略。

规划表中不得出现组合版、拼接版、多面板版或多页版输出。用户一次要求多个图时，自动拆成多个独立输出；若无法确定应拆成哪些独立科研图，只询问拆分边界，不得以组合图规避。

## 模板、源码与输出检查

模板选择时，任何天然生成多面板、分面、inset、组合画布或多页 PDF 的模板均不合格。能在不改变科研口径的前提下拆为独立输出时，只修改任务复制件；否则选择单图模板或新写单图 R 源码。

运行前必须语义检查 R 源码最终建立的数据面板数，不能只匹配包名或函数名。运行后必须确认每个 PDF 只有一页、每个 PDF/TIF 文件非空且一一配对、没有额外组合输出，并结合源码和必要的视觉检查确认只有一个主要数据面板。违反时不得进入解释同步。

## 图片目录单元

图片目录单元可以收纳多组同质独立单图，但每个成员仍必须是自己的 PDF/TIF 文件对。目录不能把多图组合到一个文件中。

目录单元必须在规划表中明确命名，并写清成员图含义、排序和命名规则。只有同一科研问题、同一图形语法、同一结果口径且成员之间只改变枚举对象时才允许作为同质图片目录；无法判断时安全停。

## 解释镜像

新输出解释根使用项目内：

`<工作记录根>/YYYYMMDD/结果/解释`

解释 txt 必须镜像结果单元库路径。汇总表中的 `父目录项目相对路径` 必须填写结果单元库中的真实输出父目录，不得填写盘符、同步根、临时工作目录或库根占位。
