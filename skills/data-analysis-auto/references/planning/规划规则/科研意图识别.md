# 科研意图识别

## 目的
把用户自然语言需求转成可执行、可复核的自动规划表。本 skill 不能直接把口语需求改写成脚本步骤。

## 必须识别的内容
- 科研目标：本次分析要回答的科学问题。
- 分析对象：本次被统计、比较、筛选、建模、绘图或解释的对象。
- 数据来源：使用哪些信息单元、图文单元、字段、工作表或文件。
- 统计单位：一条记录、一个样本、一个分组、一个时间点、一个重复或其它单位分别代表什么。
- 数据类型：数值、计数、比例、分类、矩阵、距离、文本、树或其它结构。
- 设计信息：分组、重复、配对、时间、批次、协变量、筛选条件和用户指定边界。
- 预期结果：用户需要的信息单元、图或文分别回答什么问题。
- 不确定项：无法从用户需求和解释文件确定的口径、方法或参数。

## 进入自动规划表
识别结果必须写入 `规划表.xlsx`，不能只停留在内部推理中。

- 明确的目标、对象、数据来源写入任务和输入。
- 统计单位、设计信息、方法规则写入口径与参数。
- 输出结果如何被解释写入输出解释要点。
- 影响结果正确性的关键不确定项必须触发安全停。
