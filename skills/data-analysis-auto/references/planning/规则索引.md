# 规则索引

## 读取顺序
自动规划阶段必须按顺序读取并执行以下规则：

1. `规划规则/科研意图识别.md`
2. `规划规则/自动规划表规则.md`
3. `规划规则/输出规格与脚本复现规则.md`
4. `规划规则/输出目录与图形拆分规则.md`
5. `口径规则/结果口径具体化.md`
6. `分析规则/分析方法选择原则.md`
7. `分析规则/未定义规则处理.md`

## 扩展规则
`references/planning/` 可以继续增加平行规则模块。新增模块只作为自动规划表填写依据，不替代安全停判断。

如果存在与本次任务匹配的额外规则模块，先读取模块，再把适用内容写入 `规划表.xlsx`。

如果没有已定义规则，按 `分析规则/未定义规则处理.md` 自行规划。
