# 解释文件范例（撰写前必读）

本文件给出新版解释字段示例。写解释时以可见汇总表表头为 txt 项目名；空单元格不写入 txt。

## 通用要点
- 信息单元表格类字段使用：`本单元内容`、`单元内容备注`、`第一行是否为表头`、`第一列是否为表头`、`非表头单元格含义`、`非表头各列含义`、`非表头各行含义`。
- 类型2 目录单元的 `目录单文件内容` 只说明单个成员文件内容是什么；整组如何理解、成员变化维度写入 `本单元内容`。
- 图片目录单元的 `目录单文件内容` 只说明单个成员图内容是什么；整组如何理解、成员变化维度写入 `本单元（整组）讲什么`；同质性依据写入 `同质性判断`。
- 矩阵只写 `非表头单元格含义`，不写 `非表头各列含义` 和 `非表头各行含义`。
- 非矩阵不写 `非表头单元格含义`，按实际结构写 `非表头各列含义` 和/或 `非表头各行含义`。
- `是不是表格`、`第一行是否为表头`、`第一列是否为表头` 每个单元格只写 `是` 或 `否`。严禁泛化描述，不要写"第一行是表头，定义各列字段名称"。

本图讲什么：各分组样本 pOTU Hill-Shannon 多样性的箱线图，比较不同分组的多样性分布。

## 范例 H — 类型2 · 图片目录单元
```
图文单元性质：类型2 · 图片目录单元
图文单元项目相对路径：<项目名>\03_数据与分析\主库\图文单元库\图\病毒宿主相关性\病毒宿主配对相关性散点图目录
本单元（整组）讲什么：每个病毒-宿主配对一张的跨样本丰度相关性散点图集合，用于逐配对查看病毒丰度和宿主丰度是否同步变化。
文件格式：每个成员图均为 PDF 矢量图（.pdf）
备用文件格式：每个成员图均有同名 TIF 图片（.tif，300 dpi）
目录单文件内容：单个成员图是一个病毒-宿主配对在多个样本中的丰度相关性散点图。
成员图命名规则：`pair_<编号>_<病毒ID>_<宿主ID>_correlation.pdf` 及同名 `.tif`。
成员图排序规则：按配对编号从小到大排序。
同质性判断：所有成员图回答同一个科研问题，即单个病毒-宿主配对在跨样本尺度上病毒丰度和宿主丰度是否同步变化；图类型均为散点图，横轴均为宿主 MAG/bin 丰度，纵轴均为病毒 vOTU 丰度，图注均解释样本状态，Spearman 相关和样本过滤口径一致；成员图之间只改变病毒-宿主配对编号、病毒 ID 和宿主 ID。
图类型：散点图（scatter plot）
横轴：宿主 MAG/bin 在样本中的标准化丰度
纵轴：病毒 vOTU 在样本中的标准化丰度
是否有图注：是
图注项目：
- 样本状态：黑色点代表 Plume 样本，红色点代表 Sediment 样本，蓝色点代表 Mat 样本。
- 拟合线：灰色实线代表该病毒-宿主配对在所有纳入样本点上的普通最小二乘线性拟合趋势。
方法：对每个病毒-宿主配对分别计算 Spearman 秩相关系数；线性拟合用于显示趋势，模型为 `virus_abundance = β0 + β1 × host_abundance + ε`，其中 `virus_abundance` 是该 vOTU 在样本中的标准化丰度，`host_abundance` 是该宿主 MAG/bin 在同一样本中的标准化丰度。
结果口径：每个点代表一个样本内同一个病毒-宿主配对的两个丰度观测值；横轴值是该样本中宿主 MAG/bin 的标准化丰度，纵轴值是该样本中对应 vOTU 的标准化丰度。只纳入该配对的病毒丰度和宿主丰度均非缺失的样本点；零丰度是否纳入由规划表中的过滤条件决定。
数据来源：
- <项目名>\03_数据与分析\主库\信息单元库\病毒宿主丰度\virus_host_pair_abundance.tsv：提供病毒-宿主配对在样本中的丰度。
- <项目名>\03_数据与分析\主库\信息单元库\样本信息\sample_metadata.txt：提供样本状态。
结论：图集中正斜率且 Spearman 相关为正的配对表示病毒丰度随对应宿主丰度升高而增加；负斜率且 Spearman 相关为负的配对表示病毒丰度随对应宿主丰度升高而降低。
```

## 范例 J — 类型4 · 单个表格单元
```
图文单元性质：类型4 · 单个表格单元
图文单元项目相对路径：<项目名>\03_数据与分析\主库\图文单元库\文\病毒宿主相关性\virus_host_linear_model_results.tsv
本表讲什么：病毒-宿主丰度相关性的线性模型结果表，记录不同丰度指标和过滤口径下的模型系数、相关系数、R²、p 值和 q 值。
文件格式：制表符分隔的纯文本表（.tsv）
分隔符：制表符
是不是表格：是
表格性质：普通表 · 行式（第一行为表头）
第一行是否为表头：是
第一列是否为表头：否
非表头各列含义：
- model_id：是模型编号。一个编号对应一个固定的病毒-宿主丰度模型，模型由一个丰度指标、一个样本过滤口径和一个病毒-宿主配对集合共同定义。
- abundance_metric：是丰度指标。取值说明该行模型使用的丰度列，例如 `Read_Density_RPKM` 或 `Read_Density_RPKB`；该取值决定 `host_abundance` 和 `virus_abundance` 两个建模变量来自源表中的哪一组丰度字段。
- n_samples：是样本点数量。数值等于该行模型中同时具有非缺失宿主丰度和非缺失病毒丰度的病毒-宿主配对样本点个数；一个样本点是一个样本内一个指定病毒-宿主配对的丰度观测。
- slope：是线性模型斜率。来自模型 `virus_abundance = β0 + β1 × host_abundance + ε` 中的 `β1`；正值表示宿主丰度增加时病毒丰度拟合值增加，负值表示宿主丰度增加时病毒丰度拟合值降低。
- pearson_r：是 Pearson 相关系数。以该行纳入的病毒-宿主配对样本点为观测，计算宿主丰度和病毒丰度的线性相关系数，取值范围为 -1 到 1。
- p_value：是线性模型斜率检验 p 值。检验原假设为 `β1 = 0`，备择假设为 `β1 ≠ 0`，未经过多重检验校正。
- q_value：是 BH 校正后的 q 值。对同一批模型的 `p_value` 进行 Benjamini-Hochberg 多重检验校正后得到，用于控制假发现率。
方法：使用普通最小二乘线性模型 `virus_abundance = β0 + β1 × host_abundance + ε` 估计斜率和 p 值；同时计算 Pearson 相关系数评估线性相关强度；对同一分析批次内所有模型 p 值使用 Benjamini-Hochberg 方法计算 q 值。
结果口径：一行代表一个固定丰度指标和一个固定过滤口径下的病毒-宿主丰度模型；模型观测单位是病毒-宿主配对样本点，即一个样本内一个指定 vOTU 与一个指定宿主 MAG/bin 的丰度组合。全部配对样本点口径纳入所有非缺失观测；阳性点敏感性分析只纳入病毒丰度和宿主丰度均大于 0 的观测；Read_Density_RPKB 对照口径使用 RPKB 丰度字段替代主分析丰度字段。
数据来源：
- <项目名>\03_数据与分析\主库\信息单元库\病毒宿主丰度\virus_host_pair_abundance.tsv：提供病毒-宿主配对样本点丰度。
- <项目名>\03_数据与分析\主库\信息单元库\样本信息\sample_metadata.txt：提供样本状态和过滤条件。
结论：斜率 `slope` 为正且 `q_value` 小于规划表显著性阈值的模型支持病毒丰度随宿主丰度升高而升高；斜率为负且 `q_value` 小于阈值的模型支持病毒丰度随宿主丰度升高而降低；`q_value` 不小于阈值的模型不作为显著同步变化证据。
```
