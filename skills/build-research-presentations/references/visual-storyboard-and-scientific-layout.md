# 页面故事板与科研图布局

本文件用于把科研汇报的规划变成用户可直接审阅、能在脑中想象成品的页面故事板。用于规划、检查、创建或修改实际 PPT；不创建永久规划文件，故事板在会话中呈现。

## 先定义页面语言

对承载证据的页面，严格区分四层：

| 层 | 要回答的问题 | 页面位置 | 不应写成 |
|---|---|---|---|
| 思路 | 为什么做这项比较，它补证据链的哪一环？ | 图前的小问题框、左侧逻辑区或讲述过渡 | 代码、软件、命令、参数和工作日志 |
| 结果 | 图中直接看到了什么？ | 图旁 1–3 条短句 | 因果、机制或超出图的数据推断 |
| 结论 | 这些结果对当前研究问题意味着什么？ | 证据页标题；必要时页底一句受限总结 | 对结果的逐字复述 |
| 边界 | 还不能断言什么，或哪种解释仍待区分？ | 页底、讨论区或下一页的过渡 | 藏起冲突或把假设写成事实 |

背景、问题、方法、章节过渡和讨论页可以使用中性任务标题；只有证据页默认用结论式标题。结论必须是页面证据能支持的最强表述，不用“驱动”“导致”“证明”等因果词，除非材料确实支持。

## 页面故事板格式

先给整场汇报一段不超过三句的叙事主线，说明听众应理解的核心问题、现有证据和需要讨论/决定的事项。随后逐页使用以下格式：

```text
### 第 N 页｜<标题：证据页用结论；其他页用任务>

- 页面问题：<本页要回答什么>
- 思路：<为什么做这项比较；不写工具或代码>
- 图中结果：<1–3 条可核验观察>
- 结论边界：<可支持什么、仍不能支持什么；若不适用，写“无”>
- 证据与构图：<主图、辅助图、图旁结果区、页底边界区的角色与阅读顺序>

  ┌──────────────────────────────────────┐
  │ 标题：<结论或任务>                    │
  ├──────────────┬───────────────────────┤
  │ 思路 / 问题  │ 主图                  │
  │              │ + 图旁结果 1–3 条     │
  ├──────────────┼───────────────────────┤
  │ 辅助图/对照  │ 结论边界或下一步      │
  └──────────────┴───────────────────────┘

- 素材：<项目相对路径或既有 PPT 页类型；不在面向用户的页面中显示>
```

线框不追求像素尺寸，但必须说明：每个图的主次、预期数量、文字块位置、阅读顺序和留白用途。若页面不使用某个区域，删去该区域而不是机械保留四宫格。禁止只给“页标题 + 素材候选”的抽象大纲。

## 证据密度与常用构图

“每页一个沟通任务”意味着一个主问题和一个主结论，不意味着一页只能放一张图。

- **主证据页**：1 张主图 + 1 张对照或验证图 + 1–3 条图旁结果；适合一条结论需要核心现象和必要支撑时。
- **比较页**：2–3 张采用同一比较基线的图并列或上下排列；适合处理组、时间点、样本层级或分析视角的比较。
- **证据链页**：现象、机制/关联、下游影响依次阅读；只用于这些证据共同回答同一个问题时。
- **讨论/决策页**：当前解释、替代解释、各自证据和能区分它们的下一步；不能把未决问题伪装成结论。

单图页只在该图本身是完整而复杂的核心证据、放入辅助图会损害可读性，或听众需要集中阅读细节时使用。即使是单图页，也应有简短的思路、图旁结果和结论边界，而不是孤立大图加泛泛图注。

不要为了提高密度拼接无关工作。辅助图必须承担对照、验证、机制、样本背景或结果边界中的至少一种角色；不承担角色的图放备用页或不使用。

## 图像与科学图的版式合同

- 每个图先确定原始宽高比，再使用完整适配或换版式。所有图片必须完整保留原始边界；不得裁剪任何区域，包括非信息性留白。不得拉伸、压缩、变形或以独立宽高覆盖原比例。
- 带坐标轴、图例、比例尺、统计标记或关键标签的科研图，以及其他所有图片，均默认完整适配；空间不足时拆页、缩短文字或调整版式，不裁掉任何内容。
- 同页图之间保持可比较的视觉权重。主图通常占据最大的阅读面积；辅助图不能挤到图例、坐标轴或字体无法投影阅读。
- 图旁结果是读图提示，不是第二篇摘要：优先给数量、方向、比较对象和一致性；避免“结果表明”“提示”“说明”等未经限定的解释句。
- 不把图片内部已有图注再复制成页面文字。若图自身标签过密，优先在不改变科学含义的前提下放大图、缩短其他文字或拆页。
- 不重画数据图、不重组论文 Fig 的科学 panel；可以把已有图作为独立视觉对象并列排在同一汇报页中。

## 从故事板到成品的验收

制作前，将每页映射到既有 PPT 中合适的版式或明确的自定义构图。制作后逐页对照故事板检查：

1. 听众能否在数秒内看出本页问题、标题结论和主图之间的关系；
2. 图旁是否只陈述可核验结果，结论是否留在标题或明确结论区；
3. 辅助图是否真的补足主图证据，而非降低可读性；
4. 所有图是否保持宽高比，坐标轴、图例、比例尺和统计标记是否完整、可读；
5. 代码、工具、命令、参数、工作日志和内部制作说明是否已从默认可见页面移除；
6. 使用既有 PPT 时，版式是否继承自被声明的唯一视觉参考。
