# 科研汇报内容验收

本文件只规定科研内容和来源验收。版式、字体、渲染、溢出和视觉一致性完全遵守当前 `Presentations` Skill。

## 内容选择

- 每页只承担一个清楚的沟通任务。
- 结果页遵守“思路 → 结果 → 结论 → 边界”的语义分层。思路解释为什么做这个比较或它在证据链中补什么，不罗列代码、软件、命令、参数或内部工作日志，除非听众需要评估方法可靠性或用户明确要求。
- 结果是图、表或数据中可直接核验的观察：模式、差异、数值、样本量和统计事实。结论是该结果对当前研究问题的受限回答或解释；不把描述性结果、相关性或探索性观察升级成因果结论。
- 证据页的标题默认写可由页面证据支持的结论；背景、问题、方法、转场和讨论页可用中性任务标题，不强行伪装成结论。图旁只写 1–3 条可核验的结果，不重复标题结论，也不放长段图注。
- 明确区分已确认事实、探索性观察、解释、尚未验证假设和未来计划。
- 不凭图猜结论，不把相关性改写成因果，不把缺失统计量补成确定结论。
- 全景汇报中的结果必须服务当前故事或明确标记为旁支发现。
- 组会增量可以展示失败、阴性或探索结果，只要它们属于本周期并有实际工作证据。

## 来源追溯

在演讲者备注中为关键结论保存来源：

```text
[Project sources]
- 03_数据与分析/主库/<项目相对路径> — <支持的结论或图>
- 02_实验设计.md — <板块、证据或图编号>

[Sources]
- <DOI、论文链接或权威网页> — <支持的外部论断>
```

- 使用项目相对路径，不写本机绝对路径。
- 外部非平凡论断和外部素材继续遵守 `Presentations` 的 `[Sources]` 备注合同。
- 同一来源支持多页时，仍在各相关页面保留必要说明，不依赖读者猜测。
- 不把内部筛选理由、制作计划或 agent 自言自语显示在幻灯片正文。

## 科研图边界

可以：

- 缩放和排列既有图；所有图、照片、显微图和示意图必须完整保留并保持原始宽高比。只能按一个维度缩放，并由原始比例计算另一维；不得独立拉伸宽度和高度，也不得裁剪任何图片。
- 添加不改变科学含义的标题、箭头、强调框和汇报层标注；
- 为投影可读性调整图片在页面中的尺寸和留白。

安排既有科研图时：

- 所有图片默认完整适配（contain），包括坐标轴、图例、比例尺、统计标记、关键标签和非信息性留白；空间不足时优先换版式、缩短文字或拆页。不得通过裁剪、拉伸、压缩或截断图片来腾出空间。
- 一页允许有 1 张主图和 1–3 张直接服务同一问题的辅助图。只有单图已经构成完整、投影可读的证据时才使用单图页；不能因“每页一个沟通任务”而把相关证据机械拆为多页。
- 主图、辅助图、图旁结果和结论边界须形成清楚阅读顺序。不得把多个不相干结果拼成工作日志式图集。

不得：

- 重算数据或改变统计值；
- 修改坐标、数据编码、图例含义或样本范围；
- 重新绘制数据图；
- 把现有 panel 重组为新的论文 Fig；
- 用视觉处理掩盖不支持当前结论的内容。

需要重画数据图时返回 `03`；需要改变正式 Fig 科学组合时返回 `04`。

## 逐页验收

除 `Presentations` 的视觉检查外，逐页确认：

1. 页面故事板中的问题、思路、主图、辅助图、图旁结果、标题结论和结论边界是否在最终页面中各就其位；
2. 标题是否表达本页可由证据支持的认识，且没有与图旁结果重复或混淆；
3. 图旁文字是否仅包含 1–3 条可核验的结果，而不是代码、工具、命令、参数、制作说明或泛泛图注；
4. 结论是否由页面中的证据支持，并正确保留假设、探索性观察和因果边界；
5. 一张主图与辅助图的组合是否提高理解而非降低证据密度；单图页是否确有必要；
6. 数值、样本量、统计量、单位、分组和标签是否与来源一致；
7. 图例、坐标轴、注释和显著性标记在投影尺寸下是否可读，所有图片是否完整保留原始边界、保持原始宽高比且没有裁剪、拉伸或压缩；
8. 当前假设、缺口和未来计划是否没有伪装成已完成结果；
9. 来源备注是否存在且使用项目相对路径；
10. 页面是否暴露不应对当前听众展示的内部信息。

## 整体验收

- 增量汇报能回答本周期结论、完成事项、关键结果、卡点、待判断事项和下一步。
- 全景汇报能从研究问题自然推进到证据、路线、结果、进度和后续计划。
- 相邻页面的叙事没有断裂或重复堆叠。
- 备用页与正文分界清楚。
- 所有页面已实际渲染并逐页查看；重大改版后全量复验，小改后至少复验受影响页面及相邻页面。
- 最终文件中不存在未解析占位符、临时素材或制作备注。
